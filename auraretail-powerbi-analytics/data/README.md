# Dataset Documentation

This folder contains the seven synthetic CSV datasets used in the AuraRetail Power BI Business Intelligence project.

## Dataset Inventory

| File | Description |
|---|---|
| `ecom_data_fact_sales.csv` | Sales transactions, orders, revenue, costs, discounts and quantities |
| `ecom_data_dim_customer.csv` | Customer identifiers and demographic information |
| `ecom_data_dim_product.csv` | Product details and category classifications |
| `ecom_data_dim_supplier.csv` | Supplier information |
| `ecom_data_dim_geography.csv` | Geographical attributes, including regions and states |
| `ecom_data_dim_promotion.csv` | Promotional campaign information |
| `ecom_data_dim_date.csv` | Calendar and date attributes |

## Dataset Information

- Number of datasets: 7
- Fact table: Sales
- Dimension tables: 6
- Reporting period: 2023–2025
- Fact table records: 12,500

## Data Source

All datasets are synthetic and intended exclusively for educational, analytical and portfolio demonstration purposes.

They do not represent actual company transactions or customer records.
