# Power BI Report Documentation

## AuraRetail Executive Dashboard

This folder contains the interactive Power BI report developed for the AuraRetail Business Intelligence project.

**Main file:** `AuraRetail_Executive_Dashboard.pbix`

## Report Structure

The report contains two pages:

### 1. Exploratory Analysis

A detailed analytical workspace used to investigate:

- Electronics profitability.
- Product return rates.
- Promotional performance.

It contains supporting visualisations used to examine patterns and identify business insights.

### 2. Executive Dashboard

A management-facing dashboard designed to provide a consolidated overview of business performance.

It includes four key performance indicators:

- Total Revenue
- Total Orders
- Total Customers
- Gross Margin %

It also includes four main visualisations:

- Revenue Trend
- Revenue by Category
- Revenue by Region
- Gross Margin by Category

Interactive slicers allow users to filter the report by year, product category, region and promotion.

## Technical Implementation

- Microsoft Power BI Desktop
- Power Query for data preparation
- DAX for calculated measures and KPIs
- Relational data modelling
- Interactive data visualisation

## How to Open the Report

Download the `.pbix` file and open it using Microsoft Power BI Desktop.

The report is an interactive Power BI file, not a static dashboard export.
